equations

The equations solved, and their turbulence and transport models

type
not set by default

The form of the flow equations to solve: inviscid Euler, viscous Navier–Stokes with no turbulence model, Reynolds-averaged Navier–Stokes (RANS) or large-eddy simulation (LES).

Options
ValueWhat it does
euler

Use the Euler flow equations in the simulation. These are compressible, inviscid flow equations.

viscous

Use the viscous flow equations. These are compressible, viscid flow equations which do not model turbulence.

rans

Use the RANS (Reynolds-Averaged Navier-Stokes) equations in the simulation. These are compressible, viscid flow equations with additional terms included to account for the effect of turbulence on the flow without the expense of simulating the turbulent flow structures themselves.

les

Use the Large Eddy Simulation (LES) equations.

correctionincompressible only
default over_relaxed

Non-orthogonal correction method

Options
ValueWhat it doesWhen to use it
none

No non-orthogonal correction. The implicit face-normal gradient uses the full face area vector and the explicit correction is zero.

Only for meshes that are close to orthogonal.

orthogonal

Splits the face area vector S\mathbf{S}S into an implicit part Δ=∣S∣ d^\boldsymbol{\Delta} = |\mathbf{S}|\,\hat{\mathbf{d}}Δ=∣S∣d^ along the line between cell centres, with the remainder treated explicitly.

minimum

Takes the implicit part as the projection of S\mathbf{S}S on the line between cell centres, Δ=(d⋅S/d⋅d) d\boldsymbol{\Delta} = (\mathbf{d}\cdot\mathbf{S}/\mathbf{d}\cdot\mathbf{d})\,\mathbf{d}Δ=(d⋅S/d⋅d)d, which keeps the explicit remainder smallest.

over_relaxed default

Takes the implicit part as Δ=d ∣S∣2/(d⋅S)\boldsymbol{\Delta} = \mathbf{d}\,|\mathbf{S}|^2/(\mathbf{d}\cdot\mathbf{S})Δ=d∣S∣2/(d⋅S), which grows as the mesh becomes more non-orthogonal.

The default.
