The current input format, against which the deck is validated.

Every deck sets it. A deck without config_version is read as a legacy deck and rejected.

A minimal deck

The keys every deck must set, with one boundary condition and one fluid zone. Each key links to its entry. Names in angle brackets are chosen by the deck, and ... marks optional keys left out.

config version
The deck format version. The only value accepted is 2.
solver
Settings shared by every mesh. It must set solver settings, equations, fluid properties, initialisation, time settings, numerical scheme and output settings. reference conditions and convergence control are optional.
model
One block per mesh, under a name of your choosing. Each must set mesh and boundary conditions, and may set fluid zones and transforms. Its initialisation, convergence control, numerical scheme and output settings override the solver's blocks of the same name for that mesh.
