motion

Rigid motion of the placed mesh, or the frame its flow is solved in. Its axis, origin and velocity are in placed coordinates. Coordinates go through 'scale', then 'transform', then 'motion'.

moving meshramp timeaxisrequiredoriginrequiredomegarequiredtyperequiredvelocityrequiredrotate nodesadvanced
moving mesh
bool·default False·'moving mesh' only applies when the model has an overset or sliding interface and the run is unsteady and compressible. For a steady rotor, or an incompressible run, set 'moving mesh': False to solve the flow in the moving frame.

True moves the nodes through an unsteady run. False keeps the mesh still and solves the flow in the moving frame (MRF).

Used inoverset_acoustics
ramp time
float·not set by default·> 0 s·'ramp time' only applies when 'moving mesh' is True. A frame runs at its full rate from the first step: remove 'ramp time'.

Physical time over which a moving mesh rises linearly from rest to its full rate; unset starts at full rate.
