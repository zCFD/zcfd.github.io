ValueWhat it doesWhen to use it

A thin-plate spline in the distance scaled by support_radius; it is never zero, so the system is dense.

Small surfaces where a global, smooth deformation is wanted.

inverse_multiquadric
rbf_multiscale only

Never; use c2.

gaussian

A Gaussian whose width is support_radius; it is never zero, so every pair of points interacts and the system is dense.

Small surfaces only, as the dense system grows with the square of the number of points.

linear
rbf_multiscale only

Not implemented; the run stops with an unknown-basis error.

Never; use c2.

cubic
rbf_multiscale only

Not implemented; the run stops with an unknown-basis error.

Never; use c2.

quintic
rbf_multiscale only

Not implemented; the run stops with an unknown-basis error.

Never; use c2.

c0

A Wendland C0 function that is zero beyond support_radius; the deformation is continuous but its slope is not.

Rarely; c2 gives a smoother deformation with the same sparsity.

c2 default

A Wendland C2 function that is zero beyond support_radius, so only nearby points interact and the system is sparse.

The default, and the appropriate choice for most cases.

c4

Selects a Wendland C4 function, but the matrix assembly and the volume deformation evaluate c2, so the interpolation is inconsistent.

Not at present; use c2.

c6
rbf_multiscale only

Not implemented; the run stops with an unknown-basis error.

Never; use c2.

transform type
not set by default

Mesh deformation transform used for the coupling

Options
ValueWhat it doesWhen to use it
rbf_multiscale

Deforms the volume mesh using the multiscale RBF scheme.

idw

Deforms the volume mesh using inverse distance weighting.

rbf

Deforms the volume mesh with a single-level RBF, adding surface points one at a time, worst-interpolated first, until each is within tol.

Where an error-controlled choice of points is preferred to the fixed base_point_fraction of rbf_multiscale.
