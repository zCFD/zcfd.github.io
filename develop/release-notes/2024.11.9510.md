# 2024.11.9510

## New features

- The mesher takes `--stlSpacingResolution` to control the sizing of refinement regions around each STL.
- zutil adds `ZCFD_Result`, which locates a run's report, log, output and checkpoint files from its control file.
- zutil's `include` can share variables from an included file with the calling control file.

## Changes in behaviour

- In rotating-reference-frame cases, force report columns are given in the inertial frame by default. Set `'inertial frame': False` in the report entry to keep the fixed frame. The separate `_Fif`, `_Fpif`, `_Ffif`, `_Mif`, `_Mpif` and `_Mfif` columns are no longer written.
- Mesher refinement regions use the level nearest the requested spacing; check the spacing printed by the mesher.
- zutil's `cp_profile` and `cf_profile` take a surface, slice normal and slice location. `cp_profile_span`, `cp_profile_wall_from_file_span`, `get_chord_spanwise` and `residual_plot` are removed.

## Fixes

- Improved immersed-boundary and acoustic workflows.
