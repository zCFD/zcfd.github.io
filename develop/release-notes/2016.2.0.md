# 2016.2.0

## New features

- Added an implicit time-marching scheme for the finite-volume solvers, `scheme: {'name': 'lu-sgs'}`.
- Added high-order SST solvers for detached-eddy simulation (`DGMenterDES`) and RANS (`DGRANS`), with pressure outflow boundaries and P3 hexahedra.
- Wind energy: canopy model constants can be set per fluid zone, turbine zones can be built from turbine definition files, and probe data can be exported for wind-farm analysis.
- Extended post-processing with friction moments, centres of action and spanwise profiles.
- Added scripts to start notebook and ParaView servers, plot residuals and submit cluster jobs.

## Changes in behaviour

- Results near farfield boundaries may differ from earlier versions.
- Reported residuals are normalised differently, so convergence histories are not directly comparable with earlier versions.

## Fixes

- Improved robustness of parallel and high-order runs.
