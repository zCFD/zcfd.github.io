# 2022.02.1380

## New features

- Added the `implicit euler` time-marching scheme, with linear solves on the GPU for both the compressible and incompressible solvers.
- Overset cases run on the GPU, can translate as well as rotate, and can time-average the solution.
- Added a generic FSI coupling (`fsi` with `type: "generic"`) for external structural codes.
- The SST model gains `rotation correction` and a settable `a1` constant.

## Changes in behaviour

- Abaqus FSI is configured through the `fsi` block with `type: "abaqus"`, in place of the `abaqus fsi` block.
- Moving overset meshes need `moving mesh: True` in `time marching`.

## Removals

- Removed the `lu-sgs` time-marching scheme and its settings block; use `implicit euler` instead.

## Fixes

- Improved robustness of restart and FSI workflows.
