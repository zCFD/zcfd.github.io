# 2020.06.110

## New features

- Added fluid-structure interaction with a modal structural model, set up through a `modal model` block using Nastran mode shapes, in the compressible finite-volume solvers on CPU and GPU.
- The modal model supports mode selection, per-mode damping and prescribed forcing, with output variables for mode shapes, deformation and mesh velocity.
- Added coupling to Abaqus through an `abaqus fsi` block and the `--cse-director` command-line option.
- Mesh checks report the location of any negative-volume cell.

## Changes in behaviour

- A restarted dual time stepping run takes its first real time step at first order in time.
