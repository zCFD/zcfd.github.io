# 2024.04.8259

## New features

- The incompressible solver supports moving meshes, with rotating and translating cell zones and moving walls.
- Force reports in rotating-frame cases include torque and power, and `dimensional: True` gives forces in dimensional units.
- Extended immersed-wall options, including surface output, and a `condition` key for `sponge layer damping`.
- The `zmesh` mesher accepts `--stlDistanceSpacings` to set spacing by distance from each STL.

## Changes in behaviour

- The default `inviscid flux scheme` is now `"Roe"`. Set `"HLLC"` to keep previous results.
- `qcr` takes `2000`, `2020` or `2021` in place of `True`/`False`.

## Removals

- Removed the `run_mycluster` and `run_myclusterui` scripts and zutil's remote ParaView server helpers.

## Fixes

- Improved accuracy and robustness across the solvers, output and restart.

## Platforms and packaging

- Added support for GPUs of compute capability 8.6.
