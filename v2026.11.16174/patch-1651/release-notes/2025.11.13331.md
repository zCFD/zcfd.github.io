# 2025.11.13331

## New features

- The user guide documents the incompressible solver settings for viscous, RANS and LES runs.

## Changes in behaviour

- Reported incompressible residual levels differ from earlier releases.
- Incompressible decks must not set compressible-only time-marching keys, such as `cfl`, the CFL ramp and the multigrid settings.

## Validation cases

- Added the NASA 3D bump-in-channel case for the compressible and incompressible solvers.

## Platforms and packaging

- GPU builds support NVIDIA Blackwell and require an Ampere or newer GPU.
