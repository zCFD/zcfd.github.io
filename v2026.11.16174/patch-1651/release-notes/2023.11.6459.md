# 2023.11.6459

## New features

- Implicit time marching can be used with translational periodic boundaries.
- Added gradient and immersed-boundary output variables, and acoustic surface output can be viewed in ParaView.
- New zm3 mesher options for removing volumes inside STLs, global spacing scaling and recovering the generating command line. `run_zcfd` takes `--location` to give the installation path.
- New and updated user-guide tutorials, including acoustics and aero-acoustics.

## Changes in behaviour

- Replace `double precision linear solve` in `time marching` with `double precision` in `linear solver options`.
- The default `partitioner` has changed; set it explicitly to reproduce earlier partitions.
- Rename the `velocitygradient` output variable to `velocitygrad`.

## Fixes

- Improved robustness of overset, periodic and aeroelastic workflows.

## Platforms and packaging

- zCFD runs on macOS 14.
