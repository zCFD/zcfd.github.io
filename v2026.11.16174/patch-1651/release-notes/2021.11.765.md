# 2021.11.765

## New features

- Added `su2convert`, which converts 3D SU2 meshes.
- Unsteady runs can accumulate time-averaged mean and RMS fields with `compute average and rms` in `write output`.
- A solution can be restarted on a different mesh with `interpolate restart`, and a viscous run can restart from SST or SA-neg results.
- The (I)DDES constants can be set in the `turbulence` block, and the high-order LES solver supports the WALE subgrid model.
- FRPM acoustic sources gain further inflow and near-wall controls.
- `run_zcfd --no-env-override` keeps environment variables that are already set.

## Fixes

- Improved robustness of overset, restart and mesh import workflows.
