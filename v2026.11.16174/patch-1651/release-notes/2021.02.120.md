# 2021.02.120

## New features

- Added overset meshes for the finite-volume and DG solvers, set with the `overset` boundary condition type.
- Added a further mesh deformation method for mesh transforms and fluid-structure interaction, and remote coupling to Abaqus.
- Inflow and outflow conditions can vary in space, given as a field file or a Python function.
- Forces can be reported relative to a `reference pressure`.
- Extended the incompressible solver with force reporting, restarts and additional output variables, and the DG solver with low-Mach preconditioning for unsteady runs.

## Changes in behaviour

- zCFD runs on Python 3; control files must be valid Python 3.
- In mesh transform blocks, replace the `multiscale` flag with `type` (`'rbf'`, `'rbf multiscale'` or `'idw'`). In a modal model, replace `rbf type` with `transform type`; the default `alpha` is 1.0.
- The unsteady `order` defaults to second order, and `FRPM length scale resolution factor` to 0.5; set them explicitly to keep earlier settings.

## Fixes

- Improved robustness of restart and incompressible workflows.

## Validation cases

- Added the Skyhunter UAV low-speed case to the release suite.

## Platforms and packaging

- GPUs of compute capability 3.0 are no longer supported. ParaView is updated to 5.8.1.
