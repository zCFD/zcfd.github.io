momentum

type: momentum

Momentum source fluid zone.

Typemomentumrotatingdiscporouscanopyablidw transformrbf transform
cell zonesdefinitionkindfrequencyfuncsource
cell zones
list of int·not set by default·give either 'cell zones' or 'definition', not both

Mesh cell zone numbers whose cells form the source region, for example "cell zones": [4]; give this, 'definition', or neither for the whole mesh

Guidance: Choosing a fluid-zone model →
definition
str·not set by default

Closed-surface VTP file selecting the source region cells; without it or 'cell zones' the source applies to the whole mesh

Guidance: Choosing a fluid-zone model →
kind
default fixed

Source kind

Options
ValueWhat it doesWhen to use it
fixed default

Labels the source as constant; the solver evaluates func once at start-up whatever the kind.

The default; every kind gives the same result.

ramp

Labels the source as ramped, but the solver does not read kind, so it behaves as fixed.

No effect; leave the default.

func

Labels the source as function-driven, but the solver does not read kind, so it behaves as fixed.

No effect; leave the default.

Guidance: Choosing a fluid-zone model →
frequency
int·default 1·>= 1

Update frequency

func
Python function·not set by default·accepts a Python function

Function of the cell centres giving the source, in the units of 'source', in every cell of the source, called as f(*, locations); it returns a list of one source vector of three numbers per location

Guidance: Python functions in the deck →

vector (3 floats)·not set by default
