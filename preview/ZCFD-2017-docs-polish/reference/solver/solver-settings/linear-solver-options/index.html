settings block·default shown below·'momentum' only applies when solver.convergence control.scheme.name is 'simple'

PETSc options for the SIMPLE momentum predictor (block-3) solver. simpleFoam's U entry: BiCGStab + ILU to relTol 0.1. The under-relaxed momentum matrix is strongly diagonally dominant, so this is a few iterations

    "-ksp_min_it": "1",
    "-ksp_type": "bcgs",
    "-ksp_rtol": "0.1",
    "-ksp_atol": "1.0e-12",
    "-ksp_max_it": "50",
    "-pc_type": "bjacobi",
    "-sub_pc_type": "ilu",
    "-ksp_converged_reason": "",
