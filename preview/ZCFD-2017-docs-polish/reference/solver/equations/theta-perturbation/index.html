theta perturbation

Initial potential-temperature perturbation added to the base state (gravity-wave and bubble benchmarks)

kindrequiredamplituderequiredcentrehalf widthhalf heightdepth
kindrequired
required

inertia gravity wave: A sin(pi z/H) / (1 + ((x - xc)/a)^2) (Skamarock & Klemp 1994); bubble: A cos^2(pi r/2) inside the ellipse r = |((x - xc)/rx, (z - zc)/rz)| <= 1; random: position-hashed +/-A turbulence seed below 'depth' (GABLS1)

random

A pseudo-random θ′\theta'θ′ of up to amplitude either side of zero, hashed from each cell's position and applied only below depth. The seed is reproducible and independent of the partitioning.

Seeding turbulence in a stable boundary layer, as in GABLS1.
