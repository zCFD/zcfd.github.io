# Tutorials

The tutorials teach the fundamentals of using zCFD, starting with a simple case and building up the complexity
of the simulation. They provide a good starting point for setting up your own simulations. The input files
required for each tutorial are available online, linked from that tutorial's page.

1. [Simple aerofoil](./1-simple-aerofoil.md)
2. [Steady-state RANS](./2-steady-state-rans.md)
3. [Time-accurate solution](./3-time-accurate-solution.md)
4. [Aeroacoustics (FWH)](./4-aeroacoustics-fwh.md)
5. [Overset meshes](./5-overset-meshes.md)
