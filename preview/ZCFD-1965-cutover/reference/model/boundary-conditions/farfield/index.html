kind Kind
default riemann

How the farfield state is imposed.

Options
ValueWhat it does
riemann default

Uses Riemann invariants for a non-reflecting inflow with a pressure outflow.

pressure

Uses a pressure boundary condition for both inflow (downstream pressure) and outflow (user-specified pressure).

supersonic

Uses upstream conditions for both inflow and outflow.

preconditioned

Imposes the reference condition as a supersonic inflow on every face, whatever the local flow direction.
