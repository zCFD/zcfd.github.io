limiter Slope Limiter
default van albada

Slope limiter for higher-order schemes

Options
ValueWhat it doesWhen to use it
van albada default

Default. One-dimensional: ψ=max⁡(0,2ab+ε2a2+b2+ε2)\psi = \max\left(0, \dfrac{2ab + \varepsilon^2}{a^2 + b^2 + \varepsilon^2}\right)ψ=max(0,a2+b2+ε22ab+ε2​). Smooth, symmetric, bounded in [0,1][0, 1][0,1].

The recommended general purpose choice.

van leer

One-dimensional: ψ=max⁡(0,4ab+ε2(a+b)2+ε2)\psi = \max\left(0, \dfrac{4ab + \varepsilon^2}{(a + b)^2 + \varepsilon^2}\right)ψ=max(0,(a+b)2+ε24ab+ε2​). Slightly more compressive than van Albada.

symmetric ratio

One-dimensional: ψ=max⁡(0,min⁡(1,4min⁡(σa,σb)+ε∣a+b∣+ε))\psi = \max\left(0, \min\left(1, \dfrac{4\min\left(\sigma a, \sigma b\right) + \varepsilon}{\left|a + b\right| + \varepsilon}\right)\right)ψ=max(0,min(1,∣a+b∣+ε4min(σa,σb)+ε​)) with σ=sign(a+b)\sigma = \mathrm{sign}(a + b)σ=sign(a+b). The least dissipative of the three.

none

ψ=1\psi = 1ψ=1. Unlimited reconstruction: second order everywhere, but not monotonicity preserving.

Appropriate only for smooth flows with no shocks or strong gradients.

barth jespersen

Cell-based: P(y)=min⁡(1,y)P(y) = \min(1, y)P(y)=min(1,y). Barth & Jespersen (1989) as published. Bound preserving, but only C0C^0C0: the kink at y=1y = 1y=1 makes the limiter value flicker between cycles and can stall the residual. It has no smoothness deactivation, so it limits wherever the bound binds.

Warning

"barth jespersen" is the multidimensional, cell-based Barth & Jespersen limiter. It is not the one-dimensional "symmetric ratio" function, which takes no minimum or maximum over the cell's neighbours. A deck whose results depend on the one-dimensional behaviour must set "symmetric ratio"; "barth jespersen" gives different results. See the Unreleased release notes for when this changed.

michalak gooch

Cell-based: P(y)=y−427y3P(y) = y - \tfrac{4}{27}y^3P(y)=y−274​y3 for y<3/2y < 3/2y<3/2, else 1. Michalak & Ollivier-Gooch. C1C^1C1, and P(y)≤min⁡(1,y)P(y) \leq \min(1,y)P(y)≤min(1,y), so never less monotonicity preserving than Barth-Jespersen. Deactivates in smooth flow via a grid-scaled threshold, so formal order survives refinement.

The recommended choice.

venkatakrishnan

Cell-based: P(y)=min⁡(1,(y2+2y)/(y2+y+2))P(y) = \min\left(1, (y^2+2y)/(y^2+y+2)\right)P(y)=min(1,(y2+2y)/(y2+y+2)). Smooth, but exceeds 1 for y>2y > 2y>2, so it needs the clip, which reintroduces a C0C^0C0 kink at y=2y = 2y=2.

Provided as a familiar cross-check.

Used insliding_embedded_disc
