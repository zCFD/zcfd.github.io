# 2025.05.11605

## New features

- Porous media zones and actuator discs work on moving meshes.
- Added an `entropy fix` setting to the numerical scheme.
- `run_zcfd` accepts an `https://` or `s3://` URL for the mesh or control file.
- zutil adds mesh transform helpers and acoustic post-processing, and the user guide gains an overset tutorial.

## Changes in behaviour

- When unset, `turbulence intensity` defaults to 0.01 and `eddy viscosity ratio` to 0.1; set them explicitly to keep earlier values.
- `run_fwh` writes each surface's contribution separately; use `--sum_contributions` for summed output only.

## Removals

- Removed the `mesh transform function` setting; use `scale` and `mesh transform matrix` instead.
