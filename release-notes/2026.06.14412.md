# 2026.06.14412

## New features

- Added `convert`, a single mesh-conversion command for Fluent (including CFF), SU2, CGNS and UGRID meshes, and `meshstat`, which reports a mesh's size and the memory a run will need.
- Added `generate_paraview_helpers`, which writes ParaView state files for viewing overset results.
- Added a `"velocity"` option for `roe low dissipation sensor parameter`.

## Changes in behaviour

- Volume and surface output is written in the VTKHDF format, one `.vtkhdf` file per volume and per boundary.
- Overset runs log compact mapping summaries; set `verbose logging: True` in the `mapping` block for full diagnostics.

## Removals

- Removed the discontinuous Galerkin solver (including `dgcaa`), the legacy external fluid-structure coupling and the `lpumuscl` option; use `muscl` or `umuscl`.

## Fixes

- Improved accuracy of hybrid RANS/LES and moving-mesh simulations.

## Platforms and packaging

- ParaView 6.1.1 is bundled.
