# 2026.07.14548

## New features

- Added a low-dissipation HLLC scheme, `'HLLC low diss'`, for LES and hybrid RANS/LES.
- The CGNS converter handles structured and polyhedral meshes.
- The incompressible solver writes a wider range of output variables.
- Overset assembly can use the GPU.

## Changes in behaviour

- The mesh conversion script `convert` is renamed `convert_mesh`.
- The low-dissipation settings are renamed `low dissipation sensor`, `low dissipation sensor parameter` and `dissipation sensor minimum`; the old `roe ...` names are still accepted. Results with the `'FD'` and `'DES'` sensors differ from earlier releases.
