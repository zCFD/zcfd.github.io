# 2019.11.95

## New features

- Added a blade element theory turbine model for actuator disc fluid zones, `model: 'blade element theory'`, described in the reference guide.
- Added the incompressible RANS solver, `equations: 'incomp rans'`.
- The DG solvers support isothermal and adiabatic walls, translational periodic boundaries and polynomial order 4, and the DG CAA solver gains further source and output controls.

## Changes in behaviour

- `scale` no longer accepts a function; use the new `mesh transform function` instead.
- Several DG solver defaults have changed (`inviscid flux scheme`, `shock sensing variable`, `high order filter frequency`); set them explicitly to keep earlier settings. `ldg upwind parameter` must lie between 0 and 1.
- DG control files must not set low-Mach preconditioning or wall functions, and DG restarts must use the same number of partitions.
- In the `dgcaa` block, use `rans case name` and `rans mesh name` in place of `frpm rans case name` and `frpm rans mesh name`, and `src_x`, `src_y` and `src_z` in place of `acousticsrc`. Microphone data is written to an `ACOUSTIC_DATA` subdirectory.
- Runtime-updatable settings are checked per solver; remove any key that does not apply to the solver in use.

## Removals

- The `dgeuler` equations, and the DG settings `cell order`, `approximate curved boundaries`, `use muscl reconstruction`, `br2 diffusive flux scheme`, `use rusanov for turbulence equations` and `c11 stability parameter transport`, have been removed; delete them from control files.

## Platforms and packaging

- Added support for NVIDIA Turing GPUs.
