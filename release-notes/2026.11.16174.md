# 2026.11.16174

## New features

- Added a sliding-plane interface for rotating meshes, and a low-memory implicit scheme, `mf-gmres`.
- Extended the incompressible solver to fluid zones and stratified atmospheric flows.
- Added compressible and thermal wall functions, trimming of the angle of attack to a target lift or drag, and adaptive inner-cycle convergence for dual time stepping.
- Added a mesh checker, `check_mesh`, Plot3D mesh import, more detailed residual reporting and more flexible restarts onto a different mesh. The user guide has been rewritten and published online.

## Changes in behaviour

- Control files must use `config_version: 2`; convert older decks with `update_input`. Mesh placement and motion are set in a single `transforms` block.
- Decks using the `'barth jespersen'` limiter should change to `'symmetric ratio'` to keep their current behaviour. Overset cases require `implicit euler`, `lu-sgs` or `mf-gmres`.
- Overset, low-Mach preconditioned and DES-family results differ from earlier releases; preconditioned decks may need a gentler CFL ramp.

## Removals

- Removed the `'immersed wall'` boundary condition and its output settings, the porous zone `porosity` and `direction` fields, and the actuator-disc controller type `none` (use `fixed`).

## Fixes

- Improved robustness and accuracy of wall-function, overset and restart workflows.

## Validation cases

- Added the DARPA SUBOFF fully appended submarine.

## Platforms and packaging

- Built with CUDA 13.4; requires NVIDIA driver 580 or newer. ParaView 6.2.0 is bundled. Apptainer containers are provided separately.
